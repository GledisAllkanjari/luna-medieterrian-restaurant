# Luna Bistro

A modern and responsive restaurant website designed for a fictional Mediterranean restaurant in Tirana.

## Overview

Luna Bistro is a modern restaurant website focused on a clean visual experience, responsive design, and intuitive navigation.

The project includes multiple pages for presenting the restaurant, menu, gallery, information, and contact details.

## Features

- Responsive design
- Modern restaurant layout
- Multi-page navigation
- Restaurant menu
- Gallery section
- About page
- Contact page
- Mobile-friendly layout
- Smooth interactions and animations

## Technologies

- HTML5
- CSS3
- JavaScript
